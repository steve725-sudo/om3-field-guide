# OM-3 Field Guide — install on iPhone / iPad

Option A (no install, works offline): open om3-field-guide.html from the Files app in Safari. Bookmark it.

Option B (home-screen app, full-screen, offline after first load):
1. Create a free GitHub repo, upload everything in this folder, enable Pages (Settings → Pages → main branch).
2. Open the Pages URL in Safari on the iPhone/iPad.
3. Share → Add to Home Screen.
After that it runs from the device; the service worker caches the whole app.
